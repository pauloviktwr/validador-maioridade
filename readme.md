# Validador de Maioridade Digital

Sistema para validação de maioridade com foco em minimização de dados e privacidade.

## 🚀 Tecnologias Utilizadas
- **Backend:** Java 17+, Spring Boot 3, Bean Validation (Jakarta EE)
- **Frontend:** Angular, Reactive Forms, TypeScript
- **Arquitetura:** REST API (JSON)

## 📌 Funcionalidades
- DTOs de entrada e saída com Java Records
- Custom Validator `@MaiorDeIdade` com suporte a edge cases
- Validação no lado do cliente com formulários reativos no Angular
